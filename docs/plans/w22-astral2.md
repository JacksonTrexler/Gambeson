# w22-astral2: Starbuilding t7 Manifest Starchitecture, t9 Starnest
User (follow-up.md F1, verbatim): "t7 Manifest Starchitecture. Cheap. Unit may configure and utilize Starchitect hotbar to create. `pillar`. Dismissing and returning to regular hotbar is free. Divide cost of first rank casts cost by rank, aside from power `seal` effects." / "t9 Starnest: Creates rank generators, linked horizontally or vertically by starpanes, which support new startiles layered on top of existing tiles. (Use procedural generation rules for starnest setpieces). Seals 20% * rank power. can go negative as reserve debt."
Names user-given (--human): Manifest Starchitecture, Starnest. Tree slots per w22-astral1 D2: `--prereq starway --set min_tier=7`, `--prereq manifest_starchitecture --set min_tier=9`; no role edits.

## Calls
1. Manifest = passive toggle tagged `pillar` (pinned in the last sure slot like Powerful; disabling one pillar takes all), astral, power, int. max_rank 5.
2. "Cheap": skill.py won't price a passive, so hand-set ap 1, cost 1. New generic rule: a toggle with a price (AP or cost; not a hybrid, Persona pays its own) is paid switching ON (`Unit.toggle()` -> `pay_for`), never off. No existing toggle had a price, so nothing else changes. Paid from Power (tag power).
3. Starchitect hotbar = generic Effect stat `alt_bar` (mechanic.py; title "Second hotbar ??"), tags [tag]. Toggle on -> `Unit.show_bar(tag)`; off -> `show_bar(&"")`. Pillars and always-on passives stay put (the build); every other slot belongs to the shown bar. Each bar's layout kept in `Unit.bars` (key -> slots); first time filled with its learned skills of the tag (auto); afterwards configured by hand exactly as the regular bar (HUD drags edit `hotbar`; `bar_place` refuses a skill without the tag while a second bar is up: `bar_takes()`). Key for Manifest: `power` (every Starbuilding placing skill carries it). Later class bars reuse it with another tag.
4. Switching back is free (call 2) and restores the regular bar as it was. `get_equipped()` (saves, Game.equipped) returns the regular bar while a second one is up.
5. An alt_bar toggle starts OFF (newly learned in `sync_bar`, and each battle in `_ready`) - default toggles start on; this one is paid to come up.
6. "Divide cost of first rank casts cost by rank, aside from power seal effects": read as: while Manifest is on, power skills' cost (Energy/Power price, not AP) is divided by Manifest's rank; seals are not part of a price so they stay whole. Effect stat `cost_div` (skill attribute, tags [power], amount 1 per_rank), read in `Unit.price()`. Rounded DOWN (all Starbuilding costs are 1, so rank 2+ makes their casts free; seals are the real price, astral1 call 20). It also cuts Manifest's own price while on (moot: switching off is free). "First rank" left unread beyond this (open: could mean only rank-I casts).
7. Starnest = `star_place.gd` shape `nest` (no new behaviour). Aimed cell (range rank, like Startile) gets generator 1; each next one grows AstralNexus.SPACING (6) tiles from a random earlier one in a random cardinal direction (so linked horizontally or vertically), >= SPACING (Chebyshev) from the rest, up to rank of them (fewer if the map has no room; 40 tries). Seeded by hash(cell, rank): footprint = what it lays.
8. "Procedural generation rules": `AstralNexus._lay` split into static `AstralNexus.layout(gens, wires, rng, inside, lattice, startiles, panes)` (platform diamond 2, pane runs, walkway 40/30, Stardust 30% of reach), the Nexus calling it with the same rng order (its seeded layouts unchanged), Starnest with its straight wires. Cells off the map or already holding a star layer are skipped. Laid with `Battle.lay_star` overlays (startiles over existing ground; over void they bridge). Generators power 5 (charged full, feed `radiate`), startiles lapse rank rounds unpowered (as Startile), panes/Stardust no lapse, no per-tile seal.
9. Seal: one per cast, 20% x rank of max Power, bearing `debt` - data, not code: behaviour export `seal: Effect` (stat seal, op mul 0.2 per_rank, tags [power, debt]), applied via `Unit.afflict` with source "any tile this cast laid is still its laid terrain". Generic for any star_place shape. New: a seal's pool tag `power` resolves to `power_pool()` (Energy if powered, else Starpower). Debt path is w22-negative's (seal with debt -> floor -max); plain spending unchanged (funding refuses a pool at/below 0). No Skill.gd field.
10. Starnest cost "moderate cost, high ap" (3 AP, 1), the Starway profile (not user-given).
11. Starpower HUD label: new `Reserve.abbr` + `Reserve.short()` (abbr else name's first two letters); Starpower "SP" (Stamina keeps "ST"; "PW" is powered Energy's). HUD's three reads use `short()`.
12. Tag `debt` coloured #c0504d (mechanic.py check wants one per effect tag).
13. AI: both player-only (the AI never toggles Manifest; `AI._spans` takes only point/bridge startile shapes).
14. Icons: skill.py glyph placeholders (Ms, Sn).
15. A priced toggle's spec shows "N AP on · N cost on" (Skill.spec(); skills_test.test_flags_described wants ap/cost said). Sweep's passive pass switches an alt_bar toggle on by hand before weighing (it starts off).
