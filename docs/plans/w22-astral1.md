# w22-astral1: the Starbuilding tree (t1-t6): Startile, Starbridge, Starpanel, Starpower Generator, Starway
Goal (F1 answer, verbatim in follow-up.md): astral placing skills for Wizard, Mage, Sorcerer, Adventurer; all need Power, seal Power per tile until it is destroyed.

## Readings and calls
1. Tree: new `Trees/starbuilding.tres`, shown "Starbuilding ??" (my name; user only said "Astral skills"), a tab on each of the four classes (role.py tab; roles diffs = that tab + ext_resources only).
2. Tiers: Role.tier = 1 + max(prerequisites, Branch.needs), so Startile t1; Starbridge, Starpanel after Startile t2; Generator after Starpanel t3; Starway after Generator + Starbridge would be t5, so it sets `min_tier = 6` (Skill.min_tier, Unit.tier: the user's t6; no needs: `needs` would demand 5 other learned skills). D2: Manifest Starchitecture `--prereq starway` + `min_tier 7`; Starnest `--prereq manifest_starchitecture` + `min_tier 9`.
3. Power gate: "require Power" = the caster's funding pays in Power: a powered unit's Energy (`Unit.powered()`), or a reserve whose `only` lists `power` (Starpower, w22-starpower: not yet there, the hook is ready). Skills carry tag `power` (the user's "power exclusive skills") so Mana (only `magical`) cannot pay and Starpower (when it lands, only `power`) can. `Unit.pays_power(skill)` = funding is Power; the behaviour's `fits`/`fits_at` refuses a cast otherwise. No Skill.gd field.
4. One new Behaviour `Behaviours/star_place.gd`, exports `shape` (point, line, bridge, pair), `layer` (Terrain), `seal` points and `seal_share` per rank. All five skills use it. Placing goes through new `Battle.lay_star(c, terrain, u, ...)` (lay_layer + seal + lapse), the shared "place tile" verb (none existed).
5. Seal source = Callable "this layer is still its laid terrain" (`Battle.layer_holds`): a crack, break or lift lifts the seal (holds false); lifting does not refill the pool (w22-negative).
6. Startile: range = rank (radius_per_rank 1, through modifiers). Lays an overlay startile (through = true over ground, false over void so it bridges void: enter 1). Seals 1 power. "Lasts rank rounds unpowered": `Layer.lapse` = rank; `_repair_tiles` (each round) counts `Layer.dark` while `signal_at(c) < 0`, resets in signal; at lapse it breaks (break_layer: startile -> cracked startile -> Stardust, the existing chain), which lifts the seal. Placed tiles in the Nexus are powered, so they last.
7. Starbridge: cast on a powered star tile B (in signal, layer tagged star) in range. The other end A = nearest powered star tile found scanning from B toward the caster along the dominant axis (<= SPAN 12 tiles). Fills the gap between them with startiles, `rank` columns wide (centred on the line, odd side to the left), each placed tile seals 1 (stops when the caster can't hold another seal: pool level < 1). "Two powered tiles" read as in signal. Range rank.
8. Starpanel: line of starpane tiles from the caster toward the target tile, up to casting mod (intelligence) + rank tiles away (radius_mod + radius_per_rank), each seals 1. "Casting mod" = intelligence for all four classes (note: a Sorcerer's would be charisma).
9. Starpower Generator: the Startile verb with layer = the generator (power_rank 5 stays on the tile), "shares rank with skill": the layer carries `rank` (Layer.rank = skill rank, new) and `_rank(c)` reads max(terrain power_rank, layer.rank for a generator): power = skill rank, so rank 3 radiates 3 tiles at full charge. Seals 1 + 10% x rank of max (seal points 1, share 0.1 x rank). It is a source with charge 0 when laid (the generator registers `starpower`/`charge`); charged by Starsap/Siphon as any other. Range rank. Lapse as Startile (rank rounds unpowered: a generator with no charge is "unpowered" -> a lone generator breaks unless fed: record).
10. Starway: cast on a perceived startile T (visible) in range (casting mod + rank; "mod stat total" read as the casting stat's mod, not the sum of all six); pair = T and the startile the caster stands on (both must be startile layers, neither already a Starway); lays a `starway` layer (new tile, tags star, portal; brittle, passes) on each and pairs them (`Battle.portals`). Entering one when powered (in signal) relocates the unit to its partner if free (`Battle._portal`, `move`; a walk's last tile, or `place`), not chained; breaking one erases the pair. No seal for Starway (user gave none).
11. AI: only Startile and Starbridge, for crossing void: `AI._cross_void` when it has Power (pays_power) and a void gap lies between it and its goal; the rest player-only.
12. Tests: sweep covers casts; `Tests/starbuilding_test.gd`: seal lifts on tile destroy, lapse, Starway pairing and portal, bridge, power gate, AI crossing.

## Calls added while building
13. Tree root tag `specialist` (not `magical`): a skill's kinds come from its root, and Mana pays `magical` ones; a specialist skill is paid by Energy (a powered unit's Power) or Stamina, and the gate (3) refuses Stamina. Skills tagged `astral,power,int`. `power` tag colour teal (Tags.gd, with `portal`).
14. Skill-laid tiles are breakable by blunt (new `Layer.brittle` override set by `lay_star`): a generator has no `brittle` on its terrain (Nexus generators stay inert), but "seals until destroyed" needs a way to destroy a laid one.
15. A skill-laid generator starts charged to rank/5 of capacity (rank 5 = full), so it radiates `rank` tiles at once; no lapse (it is its own source). Rank > 5 saturates at the field's 5 tiles (max_rank 5 on every skill).
16. `Layer.power` (generator rank) read by `Battle._rank()` only where the terrain is itself ranked (power_rank > 0), so a pane never takes it.
17. Lapse break = `break_layer` (startile -> cracked startile; its seal lifts at once because the layer is no longer what was laid). The crack is not then taken on to Stardust by time (damage does that).
18. Starway: no seal, no lapse (user gave none); both tiles are overlays on the startiles; entering = a walk's last tile or `place()` (a walk's passing tiles don't trigger); the partner must be free; arrival is not chained. Brittle; either end broken erases the pair (`_unregister`, tag `portal`). "Powered" = the entered tile in signal. The AI is blind to Starways.
19. Starbridge's "two powered tiles": B aimed, A the first powered star tile found scanning from B toward the caster along the longer axis (SPAN 12), gap between, rank wide. The caster need not stand on A.
20. Costs (not user-given; `costs` profile): Startile/Starbridge/Starpanel "low cost, moderate ap" (2 AP, 1 Energy), Generator "moderate cost, moderate ap" (2 AP, 1), Starway "moderate cost, high ap" (3 AP, 1). Seals are the real price.
21. Pool: `Unit.power_pool()` = Energy if powered, else a reserve listing `power` in `only` (Starpower when w22-starpower lands: set its `only` to include `power` and these skills run on it with no change). `Unit.pays_power(s)` = funding settles on that pool.
22. Casting stat: all five tagged `int` and Starpanel/Starway add the intelligence mod (the Sorcerer's would be charisma; left).
23. AI (`AI._span`, from the approach branch of act()): Startile row over the first <= 3 void tiles of the line toward its target (within reach), or a Starbridge to the first powered star tile past the gap; only with Power (not floaters/fliers). Panels, generators and Starways are player-only.
24. Tabs "Starbuilding ??" added to Wizard, Mage, Sorcerer, Adventurer (role.py tab, teal `color` so it isn't the default gray; no kind, so it shows as "CLASS · STARBUILDING ??"; each role diff is the ext_resource, one sub_resource and the tabs line). Existing tests that listed the tabs updated: casters_test (wizard/mage tree, dabblings, mage choice: + the tab), hud_test.test_adventurer_skills_screen (+ the wheel tab).
