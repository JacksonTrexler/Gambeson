# w22-ai-stars: the AI reads star terrain (routes and costs)
Goal: Stardust, Starways and lapsing startiles in the AI's path/cost reading, through the shared functions (no Starway branch in decisions).

## Readings and calls
1. Shared price = `Battle.route()` (`_route`: line price, steered Dijkstra; AI._approach/_line_up/_retreat read `price.cost`) + `walk()`/`travel()` (+ `_cross`) + `hazard()` (what ending a walk on c owes; also the HUD forecast's source).
2. Starway hop: `_route` Dijkstra gets one extra edge: from a powered portal entry (`_exit_of`, so same rule as a walk: powered, pair free) to its pair at cost 0, depth unchanged. New `_hops(u, lo, hi)` = known entries (known_ground tags portal: fog rules) whose pair is in the walk box. Any hop in the box makes the route "searching" (Dijkstra runs even with no danger), so price and walk both see it. The returned path omits the pair (the entry's step carries it: `_cross` hops after `walk`, continues if the next step is beside the pair, and a walk ending on the entry is `_portal`'d); route path ending on a hop's far end = ends on the entry. Cost only when `portals` is non-empty and a portal is in the box.
   - Blind units (foresight < 0, they walk the straight line) don't hop: same as they don't steer round hazards.
   - Not done: `reckon_reach` (a foe's reach reading) ignores Starways (its crow-distance filter would need the same hop); chains of hops (as `_exit_of` is single hop anyway).
3. Lapsing bridge: `Battle.lapse_left(c)` (rounds of dark left, -1 powered/none) and `gives_way(c)` (<= 1 left, void ground). `hazard(ends=true)` owes the unit's whole HP (a fall: slay, as bridge-break) for ending its walk on such a tile, unless it floats/flies or can't read the tile (r.net < 0). Reading: a lapse breaks startile -> cracked startile (still bears), but a cracked tile over void is lethal at the next teeter/blow; the AI shouldn't end on a bridge that is one tick from that. Owed = full HP (conservative, "never end there": dread weighs HAZARD_TILES a HP). It shows in the HUD forecast too (same estimate; HUD not touched). Standing already: no rule to leave (undone).
4. Stardust: `Battle.regrow_left(c)` (rounds to mend, signal reaching). Slice: `AI._span` (the Startile/Starbridge crossing) treats powered dust mending within DUST_WAIT (3) rounds as no gap: if the first void on the line is such dust it casts nothing (waits at the edge, the walk stops short of the hole as now); the startile row stops at it. Dark or far (mend > 3) dust is plain void. Walkability and the 99 price of void unchanged. No other decision reads void (grep: only `_span`, `_skirt`'s footing), so there is no hunting/waiting branch to change; recorded.
